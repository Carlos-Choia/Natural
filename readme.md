# NATURAL

## What is NATURAL ?

NATURAL is not another programming language.

NATURAL is a Problem Definition Language.

The purpose of NATURAL is to bridge the gap between the Human Solution Architect and the Machine Solution.

Traditional software development requires humans to make technical decisions:

- Which programming language?
- Which database?
- Which architecture?
- Which framework?
- Which infrastructure?

These choices belong to the implementation layer, not to the problem itself.

NATURAL proposes a different approach.

Humans should describe:

- Problems
- Goals
- Constraints
- Processes
- Intentions
- Desired Outcomes

The system should determine:

- Architecture
- Technologies
- Programming Languages
- Databases
- Integrations
- Generated Code
- Deployment

---

## Philosophy

For decades software development evolved through layers of abstraction:

```text
Machine Code
    ↓
Assembly
    ↓
Procedural Languages
    ↓
Object Oriented Programming
    ↓
Frameworks
    ↓
Artificial Intelligence
```

NATURAL represents the next abstraction layer:

```text
Problem
    ↓
NATURAL
    ↓
AI
    ↓
Solution
```

The user should not need to know Python, Go, Java, SQL or Cloud Infrastructure.

The user should only need to describe the problem.

---

## Human Thinking

Humans do not think in code.

Humans think in conversations.

A project does not begin with:

```python
if x > y:
```

A project begins with:

```text
I have a problem.
```

Then questions emerge:

```text
What is the problem?

Who is affected?

What is the desired outcome?

What are the constraints?

How will success be measured?
```

Through structured conversation, NATURAL transforms human understanding into machine-understandable models.

---

## The Role of AI

Artificial Intelligence is not NATURAL.

AI is a component of NATURAL.

Current AI models are powerful implementation engines.

However, they still depend on humans to:

- Define the problem
- Establish objectives
- Clarify intent
- Validate assumptions

NATURAL acts as the reasoning layer between the Human Architect and the Artificial Intelligence.

## Example

Instead of:

```sql
SELECT *
FROM products
WHERE last_sale_date < CURRENT_DATE - 90;
```

The conversation begins as:

```text
I have an inventory problem.

Products are accumulating.

What does accumulating mean?

Products with no sales for 90 days.

What do you want?

A report showing products at risk.
```

The technical implementation becomes irrelevant.

The solution becomes the focus.

## Vision

Programming is becoming a solved problem.

Problem understanding is not.

The future is not about writing code.

The future is about expressing intent.

NATURAL is an attempt to create a universal language of problem definition, allowing humans and intelligent systems to collaborate in the creation of solutions.

---

## Mission

Transform human thought into executable solutions.

Not by teaching humans how computers work.

But by teaching computers how humans think.
